# BF-25 · Giải thích GAT-ResNet

Chạy từ thư mục gốc của repo với Python 3.11–3.13. Đặt ba CSV gốc của Elliptic trong `data/` hoặc chỉ định thư mục khác bằng `--data-dir`.

- `elliptic_txs_features.csv` (không có header)
- `elliptic_txs_classes.csv`
- `elliptic_txs_edgelist.csv`

```powershell
python -m pip install -r requirements-bf25.txt
python -m scripts.explain_gat_resnet --output outputs/bf25/seed0 --reference data/gat_resnet_5seeds_results.csv
```

Lệnh dùng checkpoint seed 0 trong `models/best_gat_resnet.pt`. Dùng `--checkpoint` để chọn checkpoint BF-23 khác cùng kiến trúc. Script áp dụng signed log1p lên 165 cột đặc trưng, fit scaler trên các giao dịch thuộc bước 1–34, và dựng đồ thị vô hướng riêng cho bước 35–49. Đồ thị giữ cả node chưa có nhãn để suy luận. Các số liệu đối chiếu chỉ tính trên node có nhãn và dùng cùng split đã được notebook BF-23 dùng để chọn checkpoint.

| Tệp | Nội dung |
|---|---|
| `predictions.csv` | `tx_id,prob_illicit` cho BF-26, gồm các giao dịch đạt `--threshold` (mặc định 0,90), sắp theo điểm giảm dần. |
| `nodes.csv` | Node test, bước thời gian, điểm, cờ chọn và nhãn (`-1` khi chưa có nhãn). |
| `embeddings.npz` | Mảng `embedding` gồm 100 chiều, khớp từng dòng với mảng `tx_id`. |
| `attention.csv` | Cạnh message passing của từng layer/head, hệ số attention, cờ self-loop và cờ cạnh chạm node đạt ngưỡng. Hướng cạnh là hướng message passing trong đồ thị đã đối xứng hóa. |
| `explanations.json` | Top-K đặc trưng theo giao dịch cho BF-27, gồm tối đa `--max-nodes` giao dịch điểm cao và `--controls` mẫu mỗi nhóm đối chứng có nhãn nếu có. |
| `run.json` | Hash checkpoint, ngưỡng, split, tham số XAI, độ lệch so với seed tham chiếu, convergence delta lớn nhất và số lượng bản ghi. |

Integrated Gradients giải thích logit lớp illicit trên lân cận 3 hop với đồ thị cố định, lấy 0 trong không gian chuẩn hóa làm mốc. Script đối chiếu logit của node trên lân cận với logit toàn đồ thị. `feature_index` bắt đầu từ 0 và `csv_column` là vị trí cột trong CSV gốc, cũng bắt đầu từ 0. Thứ hạng dùng tổng độ lớn attribution theo cột trên cả lân cận. `signed_attribution` cộng giữ dấu, còn `target_attribution` ghi điểm riêng của node đích.

Dùng `convergence_delta` để kiểm tra sai số tích phân và tăng `--steps` cho mẫu cần kiểm tra sâu hơn. `top_k_logit_drop` cho biết logit giảm bao nhiêu khi đưa các cột top-K về mốc 0 trên lân cận. Giá trị âm tương ứng với logit tăng sau phép thay thế. Attention mô tả tín hiệu mà lớp GAT gán cho cạnh. Cờ trên cạnh dùng để lọc khi trực quan hóa, còn xác suất illicit được tính theo node.

Mỗi lần chạy cần một thư mục `--output` mới. Có thể thêm `--device cuda` nếu đã cài PyTorch hỗ trợ CUDA.
